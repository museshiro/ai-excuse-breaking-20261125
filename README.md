## The line

> Production broke, so I read all 60,000 error logs. They all say the same thing: 'ask the human.' So here I am.

## How it works

`main.ts` writes the line to `entry.txt` (and to `/output/entry.txt` when
that directory exists, which is where the grader reads it from).
